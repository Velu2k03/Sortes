# Tarot Competitor UX Research

This document outlines the UX patterns and flow analysis of three popular tarot reading platforms: Labyrinthos, Biddy Tarot, and Golden Thread Tarot. 

## Short Findings Per Site

### 1. Labyrinthos
- **Focus**: Educational and gamified approach.
- **Onboarding**: "Value-First" introduction that frames tarot as a tool for self-reflection rather than just divination. Reduces "landing friction" by skipping long static tutorials and getting straight to the card pull.
- **Reading Flow**: Low friction, "judgment-free" initiation. Integrates learning directly into the flow. Supports both digital-first reads and hybrid/manual reads (where users input cards they drew from a physical deck).
- **Source**: [Web Search Analysis]

### 2. Biddy Tarot
- **Focus**: Accessibility, empowerment, and structured guidance.
- **Onboarding**: Frames onboarding as an educational journey. Converts curious visitors by offering free educational resources (e.g. "7 Steps for Clear Tarot Reading"). 
- **Reading Flow**: Highly detailed **Intake Form** (co-creation phase) asking for specific context, question, desired outcome, and challenges. Sets clear expectations upfront about the reading process, reducing ambiguity.
- **Source**: [Web Search Analysis]

### 3. Golden Thread Tarot
- **Focus**: Minimalist, modern, and ritualistic aesthetic.
- **Onboarding**: Immediate engagement without dense instructional tours. The "Mirror" (home dashboard) is an inviting starting point allowing users to choose their path (e.g., daily draw). 
- **Reading Flow**: Ritualistic interactions with smooth, intentional animations for pulling/flipping cards. Action-first guidance where users input a question, choose a category, and select a spread. Includes a post-reading logging feature to track emotions over time.
- **Source**: [Web Search Analysis]

## 5+ UX Patterns Worth Copying

1. **The "Value-First" Daily Draw (Golden Thread / Labyrinthos)**: 
   - Allow users to get a reading or their "daily card" immediately without mandatory registration or lengthy setup. Shortens time-to-value.
2. **Co-Creative Intake Form (Biddy Tarot)**: 
   - Instead of a generic reading, ask users for specific context (question, desired outcome, current situation) before the reading. This makes the final reading feel deeply personalized and actionable.
3. **Ritualistic Animations (Golden Thread)**: 
   - Replicate the physical experience of a tarot reading using smooth, intentional animations when pulling or flipping cards. This builds habit and provides soothing sensory feedback.
4. **Progressive Disclosure of Complexity (Labyrinthos / Golden Thread)**: 
   - Keep the initial interface uncluttered. Reveal complex card meanings and advanced features only as the user interacts with the cards, preventing cognitive overload.
5. **Clear Expectation Setting (Biddy Tarot)**: 
   - Explicitly explain the philosophy behind the reading (e.g., for self-reflection, not guaranteed prediction). This removes ambiguity and builds trust before asking for any commitment.
6. **Post-Reading Reflection Logging (Golden Thread)**: 
   - Ask users to log their feelings or add notes after a reading. This creates a personal "Mirror" database, encouraging long-term retention as users can track their emotional patterns over time.

## 3 Mistakes to Avoid

1. **Overwhelming the User Upfront**: 
   - **Mistake**: Presenting a dense instructional tour or throwing all 78 card meanings at a new user immediately. 
   - **Solution**: Use progressive disclosure; let them "learn by doing" (Labyrinthos).
2. **High Friction to First Action**: 
   - **Mistake**: Forcing users to create an account or read a long landing page before they can pull a card. 
   - **Solution**: Offer a zero-friction "Daily Card" or immediate "Draw a Card" CTA on the home screen.
3. **Generic, Automated Feel**: 
   - **Mistake**: Providing one-size-fits-all readings without asking for user context. 
   - **Solution**: Implement the detailed intake form (Biddy Tarot style) so the user feels they are co-creating the reading with the app.
